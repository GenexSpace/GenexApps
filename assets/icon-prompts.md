# Generated app icons

Generated with the built-in Image Gen tool. Each icon used a separate generation call with a transparent background. The PNGs in this folder preserve transparency and are resized for web use. The same icons are embedded in `index.html`.

## Shared prompt

Replace `{subject}` with the corresponding subject below to reproduce each final generation prompt:

```text
Use case: stylized-concept. Asset type: single app icon for a colorful Windows 8 inspired internal app launcher. Subject: {subject}. Style: premium playful soft 3D icon, matte porcelain, rounded sculptural shapes, very simple bold silhouette, gentle ambient occlusion, slightly isometric front view. Consistent icon family: warm ivory #fff9ef main material, restrained lavender #bcb0ed and peach #EAAE87 accents. Composition: one cohesive centered icon, square canvas, icon fills 75 percent, equal clear padding. Background: genuine transparent alpha, no ground plane or background rectangle. No words, letters, numbers, logos, borders, frames or watermark. Crisp legible at 96 pixels.
```
